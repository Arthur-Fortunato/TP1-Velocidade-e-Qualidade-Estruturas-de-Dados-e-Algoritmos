Introdução

Algoritmos clássicos podem ser aprimorados para reduzir trabalho desnecessário. O Bubble Sort bidirecional é uma variação que melhora o desempenho em certos cenários.

Tarefa

Modifique o Bubble Sort para torná-lo bidirecional.
Utilize dois índices externos, esquerdo e direito.
Garanta que o maior elemento vá para a direita e o menor para a esquerda.
Teste o algoritmo com diferentes arrays.
Compare conceitualmente com o Bubble Sort tradicional.

***
Compare conceitualmente com o Bubble Sort tradicional -> O Bubble Sort tradicional percorre o array em um único sentido por passagem e leva o maior elemento para o final. Já o Cocktail Sort percorre nos dois sentidos, levando o maior elemento para a direita e o menor para a esquerda
