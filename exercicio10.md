Introdução

Algoritmos de ordenação devem ser adaptáveis a diferentes tipos de dados. Neste exercício, você aplicará o Bubble Sort para ordenar strings, reforçando o entendimento de comparações lexicográficas.

Tarefa

Modifique o Bubble Sort para ordenar strings.
Ordene listas de palavras em ordem alfabética.
Teste com diferentes conjuntos de strings.
Valide os resultados.
Documente o comportamento observado.

***
Documente o comportamento observado -> O Bubble Sort conseguiu ordenar as listas de strings em ordem, comparando as palavras e trocando suas posições quando necessário. Os testes também apresentaram os resultados esperados
