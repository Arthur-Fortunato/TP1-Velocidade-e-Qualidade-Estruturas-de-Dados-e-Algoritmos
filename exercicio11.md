Exercício 11 Instrumentação do Bubble Sort

Introdução

Mensurar custo computacional exige instrumentação explícita. Neste exercício, você aprofundará a análise do Bubble Sort contando operações reais.

Tarefa

Instrumente o Bubble Sort para contar comparações.
Conte também o número de trocas.
Execute o algoritmo para diferentes tamanhos de entrada.
Registre os resultados.
Analise o crescimento observado.

*** 
Executei o algoritmo com listas de 10, 25, 50, 75, 100 elementos em ordem inversa. Os resultados mostraram que a quantidade de operações cresce rapidamente conforme o tamanho da lista aumenta. Quando a quantidade de elementos passou de 50 para 100, as comparações aumentaram de 1.225 para 4.950, aproximadamente quatro vezes mais
